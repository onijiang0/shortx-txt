# shortx-txt

个人自用留存 & 来自 AI 编写的 ShortX 指令脚本。

## 说明

本仓库存放个人日常使用的 [ShortX](https://github.com/shortx-repo/ShortX) 自动化指令文件（`.txt`），均由 AI 辅助生成，仅供参考。

导入方式：ShortX → 导入指令 → 选择对应 `.txt` 文件。

## 指令列表

| 文件 | 功能 |
|------|------|
| `到点自动打卡.txt` | 工作日四个打卡时间点响铃提醒，自动打开钉钉并 OCR 点击打卡按钮 |
| `每天8点打开支付宝.txt` | 每天 8:00 亮屏、上滑解锁、打开支付宝并进入芭芭农场 |

## 注意事项

- 文件编码为 UTF-8 无 BOM，`@type` 不带 `shortx.` 前缀
- 部分功能需要无障碍服务权限
- 滑动坐标基于 1080×2340 分辨率，其他分辨率需自行调整
